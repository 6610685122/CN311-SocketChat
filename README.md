# CN311-SocketChat

A real-time terminal chatroom for CN311 Operating Systems course.

## Features
- Multi-threaded Server & Client
- Real-time Broadcast
- Supports up to 10 simultaneous connections (configurable)

## Setup
1. Compile:
   ```bash
   make
   ```
2. Run Server:
   ```bash
   ./server
   ```
3. Run Client:
   - Update the IP address in `src/client.c` to the server's IP (e.g., Hamachi IP).
   - Recompile with `make`.
   - Run:
     ```bash
     ./client
     ```

## Commands
- `/exit`: Exit the chat.
